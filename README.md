# ScentRanked — Best Designer Colognes for Men

Static site generated by `build.py` (Python 3 standard library only). Output goes to `public/`.
Live: https://scentranked.pages.dev (Cloudflare Pages, branch `cloudflare`; legacy Netlify: https://scentranked.netlify.app)

## Build locally
    python3 build.py
    cd public && python3 -m http.server 8000   # open http://localhost:8000

## Config (top of build.py)
- `SITE_URL`: canonical domain
- `AFFILIATE_PARAMS`: e.g. `{"ref": "YOURID"}`, appended to every yoovic.com "Purchase Now" link
- Product data: `data/products.json`. Editorial data (review copy, rankings) lives in the `F` and `ROUNDUPS` dicts in `build.py`.

## Blog posts
Add a Markdown file to `content/blog/`. The filename becomes the URL (`my-post.md` becomes `/blog/my-post/`).

    ---
    title: My Post Title
    date: 2026-10-20T09:00:00+05:00
    description: One-sentence summary for search results and the blog index.
    image: product:versace-eros-edt
    status: published
    ---
    Body in Markdown: ## headings, paragraphs, - lists, 1. lists, **bold**, *italic*, [links](/path/).

    {{product:versace-eros-edt}}

- `image`: a full image URL, or `product:<slug>` to use that product's photo.
- `{{product:<slug>}}` on its own line embeds a product card with a **Purchase Now** button. Slugs are the review URLs (`/reviews/<slug>/`). An unknown slug fails the build on purpose.
- `status: draft` keeps the post hidden.
- **Scheduling:** set `status: published` and a future `date` (always include a timezone offset). The post is skipped until a build runs after that time.
- Supported Markdown: `##`–`####` headings, paragraphs, `-`/`1.` lists, `**bold**`, `*italic*`, `[links](url)`.

## Automatic scheduled publishing
`.github/workflows/scheduled-publish.yml` runs daily at 04:15 UTC (09:15 PKT) and POSTs to a Netlify build hook:
1. Netlify: Site configuration → Build & deploy → Build hooks → Add build hook. Copy the URL.
2. GitHub repo: Settings → Secrets and variables → Actions → New secret `NETLIFY_BUILD_HOOK` = that URL.
3. You can also run it manually from the Actions tab ("Run workflow").

Posts dated before that daily run go live that day. Pushing to the repo also triggers a Netlify build.

## Netlify
`netlify.toml`: build `python3 build.py`, publish `public`, `PYTHON_VERSION=3.11`. No pip dependencies.


## Cloudflare Pages (hosting)
Build command `pip install -r requirements.txt && python3 build.py && python3 check_duplicates.py` (Pages also auto-installs requirements.txt), output `public`, root `/`.
Env var `PYTHON_VERSION=3.11` (or newer; build image v3 default is 3.13). `SITE_URL` defaults to https://scentranked.pages.dev.

- `functions/api/admin-login.js`, `admin-api.js`: admin panel backend (SHA-256 password hash + HMAC session cookie, GitHub-backed edits).
- `functions/api/form.js`: contact + newsletter forms -> KV (`STORE`), shown in Admin -> Messages. Honeypots kept. Optional Turnstile via `TURNSTILE_SECRET` (add the widget to the forms to enable).
- `functions/api/indexnow-hook.js`: called by `.github/workflows/indexnow.yml` once the new build (`/build-id.txt` == commit SHA) is live.
- Images: yoovic.com images are downloaded once into `img_cache/src/` (committed) and converted to resized WebP in `public/img/` at build time.
- `public/_redirects` and `public/_headers` are generated by build.py.

Pages environment variables (Settings -> Variables and Secrets, Production):
`ADMIN_USERNAME`, `ADMIN_PASSWORD_SHA256` (secret), `SESSION_SECRET` (secret), `GITHUB_TOKEN` (secret, fine-grained: Contents RW + Actions RW on this repo),
`INDEXNOW_HOOK_SECRET` (secret), `PYTHON_VERSION=3.11`, optional `SITE_URL`, `GITHUB_REPO`, `GITHUB_BRANCH`, `GSC_PROPERTY`, `GSC_SERVICE_ACCOUNT_JSON`, `MERCHANT_SERVICE_ACCOUNT_JSON`, `GOOGLE_INDEXING_SA_JSON`, `TURNSTILE_SECRET`.
KV binding (Settings -> Bindings): variable `STORE` -> a KV namespace (e.g. `scentranked-store`).
Deployment is Direct Upload from `.github/workflows/deploy.yml` (push to main, after Price sync, daily 04:15 UTC scheduled publish, manual). It builds, runs `wrangler pages deploy`, then calls the IndexNow hook.
GitHub repo secrets: `CLOUDFLARE_API_TOKEN` (Pages Edit), `CLOUDFLARE_ACCOUNT_ID`, `INDEXNOW_HOOK_SECRET` (same value as in Pages).
Local test: create `.dev.vars` with the secrets, then `npx wrangler pages dev public --kv STORE` (wrangler 4 needs Node 22+).
