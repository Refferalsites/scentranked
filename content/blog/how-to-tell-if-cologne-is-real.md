**Short answer:** Check the packaging (sharp printing, correct spelling, tight cellophane), make sure the batch code on the box matches the bottle, and be wary of prices far below normal. The surest protection is buying from reputable sellers with clear return policies.

## Red flags

- **Too-good-to-be-true prices,** especially on new releases.
- **Sloppy printing,** misspellings, or wobbly logos.
- **Missing or mismatched batch codes** between box and bottle.
- **A scent that fades in minutes** or smells sharp and harsh.

## Gift sets can be faked too

Counterfeiters copy popular holiday sets. The same checks apply.

## Buy smart

Read the seller's return and authenticity policies before you order, and keep your packaging until you're sure.
