    General

    Google Search Console

    Sitemap (auto-generated on every build):

    Submit it once in Search Console → Sitemaps → enter sitemap.xml → Submit. Google retired the old "ping" URL, so submit through Search Console (or the API button below). The sitemap is also listed in robots.txt.

    Analytics

    Google Merchant Center

    Feed URL (Google Shopping RSS):

    In Merchant Center → Products → Add product source → "Add products from a file" → "Enter a link to your file" and paste the feed URL. Schedule daily fetch.

      Google Indexing API

      Secret GOOGLE_INDEXING_SA_JSON: . If set, new or updated blog post URLs are sent as URL_UPDATED after each deploy (max 100 per run; Google's default quota is 200 publish requests/day).

      Note: Google officially supports the Indexing API only for pages with JobPosting or BroadcastEvent (livestream) markup. For normal pages it may be ignored. The main Google method is the sitemap, which you can submit through Search Console (also via API in the SEO tab, using a service account added as an Owner in Search Console). Setup: Google Cloud → enable "Web Search Indexing API" → create a service account → JSON key → add the service account email as Owner in Search Console → paste the JSON into the Netlify env var GOOGLE_INDEXING_SA_JSON → redeploy.
